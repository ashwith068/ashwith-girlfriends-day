# Ashwith's Girlfriend's Day Website ❤️

## Quick start
1. Open `index.html` in a browser to test it.
2. Optional: put your favorite song in this folder and name it `music.mp3`.
3. Upload the files to a GitHub repository.
4. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
5. GitHub will give you a shareable website link.

## Customize
Open `index.html` and edit the letter text near the bottom.
You can also replace `music.mp3` with any music you have permission to use.
